# Design

Advance the active memory spec to document existing modules and assign deterministic requirement IDs while preserving its active status. Stamp SpecSync 5.0.1 at 100% coverage and install all integrations.

Trust runs the build, 29 native tests, build-hook ShellCheck/syntax, and manifest validation through Fledge. Risk blocks, provenance is progressive, and Trust-managed Atlas is disabled because the repository publishes independently. The workflow pins Trust 1.0.0 immutably.
